[02] // pipelineSix passes. Zero magic.

    
Anything without a 1:1 equivalent (assembly, Yul) is isolated as a Hole node. By default: a safe TODO stub. With --ai=assist: it gets resolved, validated with gno test and pinned in gnofy.lock.

    

      
00
solc
Typed AST via standard-json. Inheritance and types resolved.

      
01
c3flatten
C3 linearization: virtual, override, super.

      
02
modifiers
Deterministic inline expansion of modifiers.

      
03
types
uint256 → u256 checked. mapping → avl.Tree.

      
04
crossing
msg.sender → runtime.PreviousRealm(). cur realm.

      
05
hole?
assembly{} → TODO stub, or --ai=assist + gnofy.lock.

[04] // open sourceDon't trust. Read.

    
gnofy is a public repository. A transpiler that writes your contract should be as auditable as the contract itself: every pass, every runtime helper, every line the AI is allowed to touch.

where to look

        internal/passes/deterministic IR passes: c3, modifiers, crossing, naming↗
        internal/codegen/gno/the emitter. same IR → same bytes↗
        gno/p/solrt/U256 + OrderedMap runtime, embedded in the binary↗
        internal/ai/the only network code. off unless you pass --ai↗
        testdata/corpus + functional flows run on a real GnoVM↗
